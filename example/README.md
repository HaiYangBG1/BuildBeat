# Example project

This fictional ledger project retains its original intent/plan, decisions and
terminal run record as a legacy-readback fixture. Its old official workflow
remains pinned, not overwritten with the new default. The regression suite runs
a copied project through the current compatibility path with scripted workers.

New work should use [work.example.md](../templates/v2/work.example.md) and the
[quickstart](../docs/v2/guide/01-quickstart.md), without copying a workflow file.
The example does not prove real AI business capability.
