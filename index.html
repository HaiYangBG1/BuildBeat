  • 一个人同时开几个会话、用几个 AI 工具

上下文归项目，不归某个人

AI 工具自带的记忆是围着人设计的，BuildBeat 是围着项目重新设计的。

02 · 做完再留一份 result.md

work.md1 / 4

delivery/work/WORK-LOGIN-REMEMBER/work.md

# 登录记住我

登录页加「记住我」，勾上后 7 天免登录；测试全过才算完。

你行，开工。

点头记进 decisions.jsonl，谁、什么时候同意的都在

这份文档别人读不读得懂也能试：让一个没看过任何上下文的只读 AI 只读这一份，看它读出了什么、哪里只能猜。

一项工作，就是一份写好的乐谱

一个你能看到的结果，比如登录页加个「记住我」，就是一项工作。要做什么、每一步怎么走的、审出过什么、你拍过什么板，都写在这份谱上，跟代码一起存在 Git 里。谁接手都从这里接着干，回头也能翻出来看它是怎么做成的。

从一行代码，查回当初的需求

三个月后看到一段代码，没人记得当时为什么这么写，问 AI 它也只能猜。指着这行代码，就能查出它是为哪项需求写的、当时定了什么、谁批准的。

复制给 AI
请帮我在这个项目里用上 BuildBeat（https://github.com/HaiYangBG1/BuildBeat）：

1. 检查本机有没有 Node 20 以上和 Git，缺了就告诉我怎么装。
2. 安装或升级 BuildBeat 运行时：
   npm view @haiyangbg/buildbeat@latest version
   npm install --global @haiyangbg/buildbeat@latest
   buildbeat --version
   如果本机装的是 6 以前的版本，并且还有没跑完的工作，先用旧版跑完或取消，再升级。
3. 读一遍 npm 包里的 SKILL.md 和 docs/guide/01-quickstart.md（在 $(npm root -g)/@haiyangbg/buildbeat/ 下），之后都按 SKILL.md 的方式干活。
4. 按快速开始把模板放进这个项目、补好 .gitignore。代码由你来写；审查默认用本机已登录的另一个 AI 命令行工具，拿不准就问我。
5. 弄好后用一两句话告诉我可以开始了。之后我只用平常的话跟你说要做什么，命令都由你来跑。
