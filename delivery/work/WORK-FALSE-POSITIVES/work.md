# 两处误报：关窗不再拦行内代码里的占位，文档检查不再误伤英文单词

## 目标

收口四项工作时撞上两处误报，都让人为了过检查去改本来没错的文字：

1. 关窗的初稿检查把行内代码（一对反引号）里的占位符原文也当成"没填完"。结果页在描述这个功能时引用了占位符原文，第一次关窗就被拒了。
2. 文档检查里拦"AI 工具导出时夹带的引用标记"的规则，写成了"出现某个三个字母的英文词就报错"，任何含这个词的英文单词（比如表示"背诵""激动"的两个常见词）都会被拦。驾驶记录和结果页因此各改过一次措辞。

做完后：

1. 初稿标记和占位符只在代码以外才算：围栏代码、缩进代码里的本来就不算，行内代码里的也不算。正文里真正没填的占位、挪到别处的标记，照旧拒绝关窗。
2. 文档检查只拦真正的导出引用标记：文件引用标记、带 turn 编号的引用标记、AI 工具用的私用区分隔符；普通英文单词不再报错。
