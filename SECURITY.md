# Security policy

## Supported versions

Security fixes are developed on `main` and released through the newest npm patch. Only the current `latest` release is supported. Verify it with:

```bash
npm view solobaton@latest version --registry=https://registry.npmjs.org/
```

## Report a vulnerability

Do not open a public issue or pull request for an undisclosed vulnerability. Use GitHub's [private vulnerability reporting form](https://github.com/HaiYangBG1/solobaton/security/advisories/new).

Include the affected version or commit, a minimal sanitized reproduction, impact, and any known mitigation. Never include live credentials, private project source, or personal data. Please allow coordinated disclosure until a fix or mitigation is available.

Ordinary bugs and feature requests should use the public issue forms.
