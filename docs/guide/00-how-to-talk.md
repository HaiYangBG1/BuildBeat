# 怎么和会话说话

[English](00-how-to-talk.en.md)

| 你说什么 | 会话做什么 |
|---|---|
| 继续这个项目 | 读项目入口和工作记录，看 `status`，说出每项工作到哪了、有什么等你决定 |
| 准备这项功能 | 写一份 work.md：目标、起因、已核实的现状、范围、待拍板、验收、计划、停止条件 |
| 接受，开工 | 记下你的接受，然后自己写代码、自己提交 |
| 送审 | 把提交交给运行时：跑项目的验证，请一个没参与写的只读 AI 审查 |
| 到哪了、需要我决定什么 | 列出这个提交的验证结果、审查问题和等你做的决定 |
| 这条问题不用改 | 记下你的裁决和理由；同一条问题以后不再拦 |
| 批准 / 拒绝 | 把你的决定记在这个提交上；批准只表示它具备合并条件 |
| 换会话 | 把没落盘的事实写进项目；新会话按项目记录接着干 |

合并、推送、部署和发布各要各的授权。

主仓有多个代码仓时，用 `buildbeat status --repo . --all-repos` 一起看；见[跨会话接续](11-session-handoff.md)。
