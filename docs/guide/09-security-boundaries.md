# 安全边界

[English](09-security-boundaries.en.md)

| 机制 | 实际边界 |
|---|---|
| 临时检出 | 验证和审查在这个提交单独的检出里跑；不是操作系统沙箱 |
| allowedPaths | 改了范围外目录的提交记为失败；不是事前的文件系统禁写 |
| 审查只读 | 审查前后比对 Git 状态，动了文件就作废；不是宿主的禁写权限 |
| push 限制 | 检出里远端的 pushurl 被移除；不保证命令无法新增远端或出网 |
| env 白名单 | 限制继承的环境变量；不隔离 HOME 下的文件、钥匙串或 SSH 文件 |
| 批准与证据 | 提交、工作说明摘要、证据都对得上才批准 |
| 决定身份 | 记录决定来自人还是 AI 会话；不写 `--as` 时按 AI 工具的环境标记判断。这是默认值，不是防伪：AI 会话仍可写 `--as human` 或清掉环境变量 |
| 锁 | 一个仓库同一时间只跑一轮审查，靠本机的锁；没有跨机器的协调 |

宿主沙箱、生产凭据隔离和服务端分支保护要平台分别提供。运行时没有 merge、push、deploy、publish 的调用路径，但你配置的任何命令仍受宿主实际权限约束。

不采集、不上传项目的使用数据；你配置的 AI 工具有它自己的数据处理方式。
