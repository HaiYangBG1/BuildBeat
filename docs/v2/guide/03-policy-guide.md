# 内置交付校验

[English](03-policy-guide.en.md)

新运行使用固定校验：工作说明已按当前内容接受；最终候选有真实命令证据和独立审查；缺失或无法核对的信息不能通过。规则语言、任意挂点和 UI 专属策略已退出产品。

校验条件随 Run 创建记录冻结。恢复时拒绝改变条件；最终批准从台账读取条件，即使没有传配置也不会省略。工作说明修改后旧接受失效，运行中的工作说明也不能换成新内容后沿用旧批准。

旧 fast/standard/controlled 名称只做兼容转换：保留原接受要求与严重度门槛。尤其 controlled 的 P3 门槛不能降为 P2。新项目只写所需明确选项，不再选择套餐。

项目的安全、接口、UI 和上线要求放在项目规范及真实验证命令中。服务端分支保护与宿主隔离仍由各自平台负责。
