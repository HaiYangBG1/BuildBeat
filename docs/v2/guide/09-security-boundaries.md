# 安全边界

[English](09-security-boundaries.en.md)

| 机制 | 实际边界 |
|---|---|
| worktree | 候选在独立目录与分支；并非操作系统沙箱 |
| allowedPaths | 越界结果不成为合格候选；不是事前文件系统禁写 |
| reviewer 只读 | 前后 Git 状态检查并阻断写入结果；不是宿主禁写权限 |
| push 限制 | 工作树配置的远端 pushurl 被移除；不保证任意命令无法新增远端或出网 |
| env 白名单 | 限制继承的环境变量；不隔离 HOME 文件、密钥串或 SSH 文件 |
| 批准与证据 | 当前候选、工作摘要、证据和冻结校验匹配才批准 |
| 并行与锁 | 同一仓库本地协调，同 Work 互斥；没有跨机器调度器 |

宿主沙箱、生产凭据隔离和服务端分支保护需要平台分别提供。Runner 没有 merge/push/deploy/publish 调用路径，但任意外部 worker 仍受其宿主实际权限约束。

不采集或上传项目使用数据；配置的 AI 工具与通知服务有各自的数据处理方式。
