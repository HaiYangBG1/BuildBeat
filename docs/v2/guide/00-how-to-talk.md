# 怎么和会话说话

[English](00-how-to-talk.en.md)

| 你说什么 | 会话做什么 |
|---|---|
| 继续这个项目 | 读取项目入口与工作记录，查看 status，识别活动 Run |
| 准备这项功能 | 写一份 work.md：目标、范围、验收条件、实施计划 |
| 接受，开工 | 记录接受后用 run 推进；已有明确授权不重复询问 |
| 到哪了、需要我决定什么 | 状态中列出候选、证据、问题、待决策对象与下一步 |
| 我已经修好了 | 核对工作树和提交，用 run --adopt 接回验证 |
| 拒绝或取消 | 记录理由，保留候选与历史；取消活动进程需要先处理持锁驱动 |
| 换会话 | 保存未落盘事实，保留活动运行现场；新会话按项目记录接续 |

工作流默认停在合并决定。合并、推送、部署和发布分别需要对应授权。
