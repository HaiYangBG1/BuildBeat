# 恢复与诊断

[English](10-recovery.en.md)

- run 自动续接已有家族的唯一未终态 Run；多个候选时必须 --run 指定。历史工作需明确 --new 才会重新启动。
- 中断步按台账重跑自身；脏工作树先处理。手修并提交后用 --adopt 指定实际 HEAD，从 verify 继续。
- 只有同机且持有者进程已不存在的锁自动回收。活动、异机、缺持有者信息的锁保留；stop 不是杀进程命令。
- 超时、崩溃、无效信封、exit 75 属于 infra，不派 fixer、不扣失败预算。环境恢复后按待决策对象处理并续跑。
- 台账损坏只读取合法前缀，拒绝追加；history --verify 校验回放，不会静默修复。保留现场与候选后决定恢复方式。
- 运行配置或冻结校验变更时拒绝恢复。新主版本不继续不支持的旧自定义/上线流程；见迁移指南。
- runtime 被删后，终态记录可读，活动运行的现场不能凭 Git 自动恢复；不要把删 runtime 当作日常清理。
- gc 先给计划，只清终态且已归档的运行。脏树默认保留，唯一候选引用保留，失效锁需证实持有者已退出。
- STALLED 默认指 15 分钟无输出，status 给出实际耗时、历史中位数、最近输出；它只提示，不自动杀进程。
