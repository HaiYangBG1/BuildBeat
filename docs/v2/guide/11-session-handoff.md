# 跨会话接续

[English](11-session-handoff.en.md)

关闭旧会话前，将目标、决定、未验证范围和下一步写入项目；检查 Git、候选与运行状态。保留活动 Run 的台账和工作树。

新会话读取项目 AGENTS.md、Work 的 work.md（或旧 intent/plan）、决定与 status。能从记录查到的事实自行核对，沿用仍有效的授权；不把开新会话等同于重开 Run。

换工具时重新配置命令、鉴权和输出合同；接手事实可以复用，具体工具执行能力需要验证。换人时同步候选、记录和权限，说明当前推进人及下一步。

换机器只能通过 Git 同步长期事实。活动进程、运行时文件、工作树和宿主资源不会随 clone 迁移，先核对原环境再选择接手方式。

跨会话演示不等于所有工具组合都已验证。
