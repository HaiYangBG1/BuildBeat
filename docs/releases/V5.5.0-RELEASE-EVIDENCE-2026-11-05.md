# v5.5.0 发布证据（2026-11-05）

> 授权：所有者在会话里说「发 5.5.0」；版本号按新增能力定为 5.5.0（次版本，已有行为里只有"没看过的生成初稿不能关窗"一处是新加的限制）；稳定版通道：从 `main` 顶端以稳定 tag 发布到 dist-tag `latest`。

- 内容：自 5.4.0 起的改动都已在 `main`：
  - 没跑 Run 就做完的工作，`status` 显示 `COMMITTED`；`decide --action close --draft` 按提交写 `result.md` 初稿，没看过的初稿不能关窗（WORK-COMMITTED-WORKS，PR #124，收口 #125）。
  - `buildbeat hooks install` 装 commit-msg 钩子自动补 `Work:` 标记；`history --path` 在没有其他线索时按标题里唯一的编号认工作（`via subject`）；`accept`/`check` 提醒缺标记（WORK-COMMIT-TRAILERS，PR #124，收口 #125）。
  - `release --env` 和 `status --releases`；只记回读的配置让没跑 Run 的工作也能记回读；新增操作手册模板（WORK-RELEASE-ENVS，PR #124，收口 #125）。
  - 合并决定点用 `--adopt` 交回的修复不再被当成合并批准（WORK-ADOPT-NOT-APPROVAL，PR #124，收口 #125）。
  - 关窗初稿检查不再拦行内代码，文档检查的引用标记规则不再误伤英文单词（WORK-FALSE-POSITIVES，PR #126，收口 #127）。
  - `lessons.md` 第 28 条（#125）。
